# Framatic

## Project Overview

Framatic is a Flutter mobile app that helps artists frame landscapes by providing live camera viewfinder overlays with customizable aspect ratios. It is inspired by physical frame cutouts artists traditionally use for composition.

## Features

1. Capture pictures in desired aspect ratios with a polaroid like border from front or back camera from your phone
2. Preview it and then save to gallery or discard
3. Configure the frames for your quick access on the camera screen
